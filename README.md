# data-qd-245 · 多资源工位放置

`Pool.reserve(job, Demand(cpu, memory, labels))` 找出具备所需标签且同时有两种
资源余量的工位，以「扣减后的 CPU、扣减后的内存、工位名」排序取第一项。成功会
持有两个维度的名额并返回绑定供调用者调度；无合适工位返回 `None`，不扣资源。
`release(lease)` 只释放本次绑定，旧凭据或自行构造的对象无法释放当前作业的占用。
并发抢同一名额只允许一个成功。

Python 3.9+，标准库。资源为正整数单位，工位集合固定；只负责进程内资源记账
和选择，不读取真实硬件，也不启动任务。没有队列、公平性、超时、迁移、持久化或
多作业原子放置。演示用两个临时目录表示工位，并根据绑定读取实际文件。

```sh
python3 -m unittest -v
python3 demo.py
```

带标签作业先因内存不足被拒；无标签作业改落另一台。释放占用后，带标签作业
绑定到原来不能接收它的工位，调用方读取到该工位独有的 `local-model-v1`。
